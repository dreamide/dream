# Workspace, Browser tab and Chat run ownership

## NOV26-01 Project close cleanup

Status: implemented. The workspace document reports Projects that move from
open to closed. Local Chat deletion, a standalone switch, and catalog changes
apply terminal and runtime cleanup once. A close keeps the Project and Chats
available for restoration. Validate repeated catalog deletion and local actions.

## NOV26-02 Browser tab errors

Status: selected. Each tab owns its transient error and loading state.
Background navigation and desktop action errors affect the originating tab.
Verify retry, tab closure, Project closure, and events for a closed tab.

## NOV26-03 Chat run queue submission

Status: selected. A fresh enqueue resumes the queue in the same durable
operation. A duplicate preserves Pause. Verify both orderings of Pause and
submission, delayed receipts, and Stop while the scheduler claims work.
